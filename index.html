공유 저장소 연결

둘이 같은 내용을 보려면 무료 데이터베이스를 한 번 연결해야 합니다. 5분이면 끝납니다.

  1. console.firebase.google.com 에서 구글 로그인 후 프로젝트를 하나 만듭니다. (Analytics는 꺼도 됩니다)
  2. 왼쪽 메뉴 빌드 → Realtime Database → 데이터베이스 만들기. 위치는 아무거나 골라도 됩니다.
  3. 규칙 탭에서 내용을 아래로 바꾸고 게시합니다. { "rules": { ".read": true, ".write": true } } 테스트 모드를 그대로 두면 30일 뒤 잠겨서 지도가 멈춥니다. 꼭 바꿔주세요.
  4. 데이터 탭 맨 위에 보이는 주소를 복사해 아래에 붙여넣습니다.
